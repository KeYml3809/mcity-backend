# MCity Manga Backend

Этот архив содержит готовый бэкенд для сайта MCity Manga (профили, лайки с кулдауном 3 часа, система карточек от D до SS).

## Как запустить и развернуть (даже если вы новичок):

1. **База данных (Supabase):**
   - Зайдите в ваш проект на Supabase.
   - Откройте вкладку **SQL Editor**.
   - Скопируйте содержимое файла `schema.sql` и нажмите **Run**, чтобы создать таблицы.
   - Скопируйте строку подключения к БД из настроек (Connection String -> URI).

2. **Загрузка на GitHub:**
   - Распакуйте этот архив в папку на компьютере.
   - Создайте новый репозиторий на GitHub и загрузите туда эти файлы (`server.js`, `package.json`, `schema.sql`).

3. **Бесплатный хостинг (Render.com):**
   - Зайдите на [render.com](https://render.com) (можно войти через GitHub).
   - Нажмите **New -> Web Service** и выберите ваш репозиторий.
   - Укажите:
     - **Build Command:** `npm install`
     - **Start Command:** `node server.js`
   - В разделе **Environment Variables** добавьте переменную:
     - Ключ: `DATABASE_URL`
     - Значение: ваша строка подключения из Supabase (из пункта 1).
   - Нажмите **Create Web Service**. Готово! Ваш сервер получит ссылку вида `https://...onrender.com`.
